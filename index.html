Vanilla Javascript

Vanilla JavaScript is plain, pure JavaScript — without using any libraries or frameworks like jQuery, React, or Angular. It allows you to create dynamic, interactive web features such as sliders, pop-ups, form validation, and animations directly with the core JavaScript language.

Reaact

React is a popular JavaScript library for building fast, dynamic, and interactive user interfaces, especially for single-page applications. Developed by Facebook, it allows developers to create reusable UI components and manage application state efficiently.

Node.Js

Node.js is a powerful, server-side JavaScript runtime environment that allows developers to build fast and scalable web applications. It enables JavaScript to run on the server, making it possible to create backend APIs, handle databases, and manage server logic using a single programming language.

MongoDB

MongoDB is a NoSQL database that stores data in flexible, JSON-like documents, making it ideal for modern, scalable applications. It allows developers to handle large volumes of unstructured data with high performance, easy scalability, and real-time data access.
